# Changelog

## 0.1.0 (unreleased)

First version, for GNOME Shell 51.

- **Lucent Launcher**: keyboard launcher with apps, windows, files, calculator, conversions, system
  actions, timers, definitions, web shortcuts and commands; preferences window; dark and light.
- **Lucent Glass**: readable tints for menus, the calendar and notifications, chosen per surface
  from the text the theme draws; four levels of top-bar smoke; text shadow; Quick Settings and calendar as Control Centre-style glass panels, with the screen behind blurred and dimmed.
- **Lucent Tiles**: system, activity (builds, downloads, commands, media with a player card) and
  tray-drawer tiles for the top bar, with a clock quote at login and wake; preferences window.
- **Lucent Dock**: magnification for Dash to Dock, drawn by clones above the dock so the dock
  itself is never modified; size, reach and settle time.
- **Lucent Dissolve**: mist, pixels and soft-fade window-close animations; follows reduced motion.
- **Lucent Corner**: hot corner for Quick Settings with a dwell setting.
- Design tokens with build-time contrast checks; release checks; development probe.
